# AI Trading System (Educational Project)

This is an AI-powered stock market analysis and paper trading system.

## Features
- Stock & crypto data (Yahoo Finance)
- Technical indicators (RSI, MACD, SMA)
- AI prediction model (Random Forest)
- Backtesting engine
- Paper trading simulation
- Streamlit dashboard

## Assets
AAPL, TSLA, NVDA, SPY, BTC-USD

## Run Project

```bash
pip install -r requirements.txt
streamlit run dashboard/app.py
